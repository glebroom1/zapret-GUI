# zapret GUI 0.8.1-beta.1

В этом предварительном выпуске решены проблемы автозапуска при старте Windows на основе рекомендаций Gemini Argon:

### Что исправлено:
1. **Запуск без всплывающего окна UAC при входе в систему:**
   - Автозапуск переведён на задачу Планировщика Windows (`Task Scheduler`) с наивысшими правами (`RunLevel Highest`), триггером `AtLogOn`, включённой работой от батареи на ноутбуках и снятым лимитом времени 72 часа.
   - Устранён назойливый диалог «Разрешить вносить изменения на компьютере» при каждой загрузке системы.
   - Старый ключ реестра `HKCU\...\Run` автоматически очищается.
2. **Гарантированный запуск сразу в трее (`--tray`):**
   - Устранена проблема, когда окно распахивалось на рабочем столе из-за задержки инициализации системного трея Explorer при старте системы.
   - Главное окно теперь гарантированно остаётся скрытым при флаге `--tray`, а инициализация значка в трее повторяется по таймеру до готовности Explorer.
3. **Автоматическое подключение (`--connect`):**
   - В параметры задачи автозапуска включён флаг `--connect`, благодаря чему zapret сразу начинает работу с сохранённой стратегией.
4. **Устойчивость фонового процесса движка:**
   - Добавлен корректный перехват и резервный запуск движка при ограничениях Windows Job Objects.
