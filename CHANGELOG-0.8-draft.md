# Changelog 0.8.0-beta.6 — проект для релиза

Изменения относительно 0.7. Версия локальная, не опубликована.

## Дополнения beta4–beta6

- Исправлены ручная смена стратегии и выход из скрытого окна.
- Полный выход из GUI оставляет zapret включённым. Пункт трея прямо сообщает об этом.
- При повторном запуске GUI проверяет процесс и восстанавливает управление и стратегию.
- Права администратора запрашиваются сразу, до открытия окна. При автозапуске также требуется подтверждение UAC.
- Движок запускается отдельно от GUI. Проверки и автоматическая смена стратегии продолжаются, пока GUI работает, включая трей.
- Существующая кнопка и дизайн сохранены.
- 206 тестов прошли. Реальный UAC и работа WinDivert в сети вручную не проверены.

## Добавлено
- Закрытие окна в системный трей с сохранением работы соединения.
- Меню трея: открыть окно, отключить движок и выйти.
- Один экземпляр приложения: повторный запуск открывает существующее окно.
- Автозапуск при входе в Windows отдельным переключателем; запуск сразу в трей.
- Проверка новых стабильных версий приложения после запуска и по кнопке.

## Изменено
- Название окна: zapret GUI.
- Выбор сборки, использование папки без копирования и импорт ZIP/папки объединены в общий блок.
- Кнопки использования папки и импорта расположены в одном ряду.
- Исправлена компоновка полей Game Filter, IPSET и настроек проверок; интервал расположен рядом с подписью.
- Из подсказки Game Filter удалён пример с Helldivers 2.

## Подготовка сборки
- Исправлено имя результата в build/build_qt.cmd и PACKAGING.md: Zapret-GUI-0.8-beta3.exe. Ранее скрипт проверял старое имя и мог сообщить об ошибке после успешной сборки.

## Ограничения
- Проверка обновлений открывает страницу релиза; автоматической установки нет.
- Предварительная проверка запасных стратегий без прерывания текущего соединения не реализована.
- Исправление проблем Helldivers 2 не заявляется.
- Совместимость с конкретным провайдером требует проверки на его сети.
