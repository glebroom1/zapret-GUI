# Разбор Windows read-only ревью 3a109b6e

Проверен сохранённый отчёт Виктора Петровича `zapret-gui-review-3a109b6e.txt`.
Изменения beta3 проверены по исходникам, 228 тестам и конечному EXE.

1. Фактическая команда Планировщика теперь читается из XML задачи.
2. Перед UAC выполняется попытка показать существующий GUI через IPC.
3. Сервер IPC читает команду show; фоновый запуск не раскрывает окно.
4. Замечание о вечной блокировке после падения не подтвердилось: Qt проверяет
   живой PID даже при staleLockTime=0. Автоматический тест аварии отдельного
   процесса проходит; небезопасное удаление чужой блокировки не добавлялось.
5. Повторный --connect больше не ждёт 10 секунд.
6. Отдельная подтверждаемая остановка зависшего Telegram worker проверяет
   образ, командную строку и время создания и использует удерживаемый HANDLE.
7. Для начальной фазы starting не выполняется HTTP-запрос на порт 0.
8. psutil уже защищает terminate от повторного использования PID; это замечание
   не подтвердилось. После явной остановки теперь удаляется engine-session.json.
9. Маскируются секрет MTProto и ключ контроллера, включая traceback и startup-error.
10. Отказ при двух активных физических адаптерах сохранён как явное ограничение
    режима прямого выхода. Автоматический выбор маршрута не заявлен и в beta3
    не добавлялся. Приложение не меняет сетевые настройки пользователя.

Тесты не подменяют живую проверку входа Windows, UAC между уровнями прав,
Планировщика после переноса EXE, WinDivert и обмена сообщениями/медиа Telegram.
