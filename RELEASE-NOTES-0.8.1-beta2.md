# zapret GUI 0.8.1-beta.2

Добавлен отдельный локальный прокси для Telegram Desktop на базе Flowseal tg-ws-proxy.
Исправления автозапуска из beta.1 сохранены. Основная кнопка zapret и её оформление сохранены.

## Telegram

- Отдельный блок: запуск, остановка, состояние процесса, подключение в Telegram и копирование ссылки.
- Прокси слушает только `127.0.0.1`. Ссылка работает на этом компьютере.
- Полный выход GUI оставляет прокси работающим. Повторное открытие восстанавливает управление;
  остановка доступна только для подтверждённого собственного процесса.
- Секрет постоянный, защищён Windows DPAPI и не передаётся в командной строке или журнале.
- По умолчанию выбран прямой выход через единственный активный физический Wi-Fi/Ethernet.
  VPN и системные маршруты не меняются. Если такой адаптер не найден или прямой DNS недоступен,
  прокси сообщает об ошибке, без скрытого перехода на VPN.
- Доступен обычный системный маршрут: снимите галочку прямого выхода перед запуском.
- Запасной маршрут CF включён по умолчанию. Публичный пул Flowseal можно заменить своим
  базовым CF-доменом. Снятие галочки CF оставляет только прямые маршруты Telegram.
- Telegram-прокси запускается вручную. Автозапуск Windows по-прежнему относится к zapret;
  отдельный автозапуск Telegram в эту бету не добавлен.

## Проверки и ограничения

Выполнены локальные тесты жизненного цикла, защиты управления и интерфейса.
Проверен начальный MTProto-обмен через настоящий локальный прокси по обычному WS
и медиа-маршруту H2, напрямую через Wi-Fi при работающем VPN. Проверена независимость
от процесса GUI. Это не проверка переписки, скачивания фото/видео, звонков или всех DC.
Публичные CF-домены могут перестать отвечать; это не собственная инфраструктура проекта.
Автоматического подключения или изменения настроек Telegram при запуске GUI нет.
