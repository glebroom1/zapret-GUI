# zapret GUI 0.8.1-beta.3

Локальная Windows-бета от 11 ноября 2026. На GitHub не опубликована.

Изменения после beta2:

- Автозапуск сверяет фактическую команду Планировщика; после переноса EXE
  нужно один раз запустить приложение из нового места для обновления пути.
- Пути с апострофами корректно передаются PowerShell при регистрации задачи.
- До запроса UAC выполняется попытка активации уже работающего GUI.
- Повторный запуск с `--tray` не раскрывает окно; IPC читает команду `show`.
- Убрано десятисекундное ожидание блокировки при повторном `--connect`.
- Начальный статус Telegram worker отображается как запуск, без запроса на порт 0.
- Для неотвечающего TG worker доступна отдельная принудительная остановка
  с подтверждением в GUI. Проверяются время создания, образ и командная строка;
  остановка идёт через тот же удерживаемый Windows HANDLE, а не по PID отдельно.
- Секрет прокси и ключ управления маскируются в ошибках, включая traceback.
- После явной остановки движка удаляется соответствующий файл состояния.

Основная кнопка подключения и дизайн сохранены. Прокси продолжает работу после
выхода из GUI. Прямой режим пока требует одного активного физического адаптера
с IPv4-шлюзом; при двух адаптерах выводится понятная ошибка.

Проверки: 228 автоматических тестов; среди них реальные локальные процессы,
IPC между отдельными процессами, восстановление после аварии владельца lock,
остановка зависшего worker и отказ завершать чужой процесс. Это не испытание
реального WinDivert. Самопроверка конечного EXE прошла; 33 встроенных Python-модуля
совпали с исходниками. На конечном EXE проверены контроль состояния worker,
принудительная остановка и маскировка журнала.

Ограничения: реальный вход Windows, UAC между процессами разного уровня прав,
перенос зарегистрированного EXE в живом Планировщике, переписка/медиа/звонки Telegram
в этой сессии не проверены. При одновременном первом запуске двух копий возможны
два запроса UAC, но блокировка допускает только одно окно GUI.

Архитектура дополнительно обсуждена с Gemini 4 Argon по описанию; исходники целиком
ему не передавались, тесты он не запускал. Его замечания проверены по коду.
