## Изменения

- Работа в трее и автозапуск с Windows.
- После выхода из GUI zapret остаётся включённым. При повторном открытии восстанавливаются управление и текущая стратегия.
- Добавлено автообновление: уведомление о новой версии и переход к загрузке.

## Исправления

- Исправлена смена стратегии при работающем zapret, включая режим автоподбора.
- Исправлен выход из скрытого окна.
- Права администратора запрашиваются сразу при запуске.
- Исправлены расположение кнопок импорта и отображение полей настроек.

## Ограничения проверки

Сквозной сценарий с реальным WinDivert — включение, выход, повторное открытие, смена стратегии и отключение — пока не подтверждён. Запуск GUI в режиме администратора проверен, подтверждение UAC вручную — нет. Проверка через GUI остановилась из-за ошибки инструмента управления.
